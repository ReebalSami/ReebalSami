## About

I'm a **Data Scientist & AI Engineer** based in Hamburg. Five-plus years at **OTTO Group** as a Bilanzbuchhalter (SAP FI-CO/BPC, IFRS/HGB, UiPath RPA) — then a full pivot into ML/AI. Today I build end-to-end AI systems: multi-agent LLM pipelines, deep-learning vision, RAG, full-stack web on AWS.

## Currently

- Finishing my **M.Sc. thesis at FH Wedel** — *Document Intelligence and Knowledge Graph Construction*: OCR-free extraction with **Donut + LayoutLMv3**, entity resolution, **GraphRAG** reasoning over local LLMs. Fully local, zero cloud.
- Working through **AWS Cloud Practitioner**, **AI Practitioner**, and **ML Engineer** certifications.
- Shipping cloud-deployed ML projects on **AWS CDK**.

## What I Build

- **LLM-powered systems** &mdash; multi-agent apps (Agno / LangChain), crawlers, RAG, structured outputs with Pydantic
- **Deep Learning for Computer Vision** &mdash; ViT, DINOv2, ConvNeXt, ResNet-50, Grad-CAM / Attention Rollout
- **Classical ML** &mdash; bankruptcy prediction, recommenders, time series, econometrics
- **Full-stack web** &mdash; Next.js 16, React, Spring Boot, FastAPI, AWS CDK, Tailwind v4
